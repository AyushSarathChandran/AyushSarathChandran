## 🚀 Projects

### 🔍 Explainable Deepfake Video Detection Platform
[View Repo →](https://github.com/AyushSarathChandran/Deepfake-Video-Detection)

> `Python` `PyTorch` `FastAPI` `React` `OpenCV` `Grad-CAM`

- Built a deepfake video classifier using a ResNet18 backbone with multi-frame majority voting to improve prediction stability across video sequences.
- Applied Grad-CAM to generate heatmaps localizing manipulated facial regions, adding an explainability layer to model output.
- Used OpenCV for frame extraction and preprocessing; served predictions through a FastAPI backend to a React dashboard for reviewing results alongside heatmap overlays.

### 🏨 Multilingual AI Receptionist
[View Repo →](https://github.com/AyushSarathChandran/AI-receptionist)

> `Next.js` `Google Generative AI` `LangChain` `STT` `TTS`

- Built a multilingual conversational assistant integrating Google Generative AI via LangChain, applying prompt design and dialogue-state tracking to support multi-turn interactions for hotel booking scenarios.
- Integrated Speech-to-Text and Text-to-Speech APIs for a voice-based interface.
- Implemented session-based state so the assistant retains booking context across a conversation.
