## 🚀 Projects

### 🔍 Explainable Deepfake Video Detection Platform
> `Python` `PyTorch` `FastAPI` `React` `OpenCV` `Grad-CAM`

Addressing the **"Black Box" problem** in AI-based media forensics through Explainable AI (XAI).

- 🧠 Built a full-stack deep learning application to classify video authenticity, achieving high-confidence detection via a **multi-frame majority voting algorithm**.
- 🔬 Implemented **Grad-CAM (Gradient-weighted Class Activation Mapping)** to generate visual heatmap overlays, pinpointing manipulated facial regions and artifact boundaries — making the AI's reasoning fully interpretable.
- ⚙️ Engineered a high-performance **FastAPI + OpenCV** backend handling asynchronous video processing and frame-level inference with a **ResNet18** backbone.
- 🖥️ Designed a responsive **React + Vite** analytics dashboard enabling forensic investigators to review original clips alongside AI-generated explainability overlays side-by-side.
- ⚡ Optimized inference latency through strategic **frame sampling**, reducing processing time without compromising classification accuracy.

**Key Tech:** PyTorch · Torchvision · ResNet18 · Grad-CAM · FastAPI · OpenCV · React · Vite · Tailwind CSS · REST APIs

### 🏨 Multilingual AI Hotel Receptionist
> `Next.js` `Google Generative AI` `LangChain` `STT` `TTS`

A high-performance AI receptionist built for seamless, natural language hotel reservations across multiple languages.

- 🎙️ Integrated **Speech-to-Text (STT)** and **Text-to-Speech (TTS)** for a fully voice-driven, hands-free guest experience.
- 🌍 Supports **multilingual conversations**, enabling natural hotel bookings across language barriers without switching interfaces.
- 🧠 Powered by **Google Generative AI + LangChain** for context-aware, multi-turn dialogue that handles complex reservation flows.
- 📅 Built a **persistent booking system** to reliably store, retrieve, and manage reservations across sessions.
- ⚡ Optimized for performance with **Next.js**, ensuring fast load times and a smooth, production-grade user experience.

**Key Tech:** Next.js · Google Generative AI · LangChain · Web Speech API · STT · TTS · Persistent Storage
